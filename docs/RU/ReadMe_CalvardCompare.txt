Сверка перевода (CalvardCompare) 0.2 — Trails through Daybreak, Daybreak II, Trails beyond the Horizon

ЧТО ДЕЛАЕТ
  Показывает текст двух языков рядом, строка к строке (японский, английский или русский — в любой паре,
  обычно оригинал слева и перевод справа), с поиском по обоим столбцам и словарём, а на вкладке «Проверки» —
  ошибки перевода: потерянные служебные коды, непереведённое, подстановки.
  Файлы перевода Сверка только читает — ничего в них не пишет.
  Нужна видеокарта с OpenGL 2 и выше.

──────────────────────────────── БЫСТРЫЙ СТАРТ

  1. Левое поле «Английские/Японские/Русские файлы» — оригинал, одно из:
     • сама папка игры (где лежит script_eng.p3a или script_en.p3a) — английские диалоги и таблицы
       Сверка разберёт из архива сама: первый раз до минуты, дальше из кэша (около секунды);
     • папка проекта CalvardTool с английскими файлами;
     • японские файлы: CalvardTool разбирает японские сцены и таблицы игры (архив script.p3a) в папку
       проекта «script» — укажите эту папку (Проект\script). Если перевод сделан с японского (как DB1),
       так «Проверки» сверяют коды с тем текстом, с которого переводили.
  2. Правое поле — перевод: папка проекта CalvardTool, где разобран перевод (там mods\RU_MOD\…).
     Можно указать одну и ту же папку проекта в обоих полях: русский берётся из mods, английский —
     из файлов игры и папки _english.
     Папки можно перетащить в окно: левая половина — левое поле, правая — правое
     (две папки сразу — первая слева, вторая справа).
  3. «Загрузить». Впишите слово и нажмите Enter.

──────────────────────────────── ЗАГРУЗКА

  • При запуске Сверка сама загружает последние папки и открывается там, где вы остановились:
    то же слово поиска и строка, та же вкладка, раздел «Проверок», раскрытая группа и прокрутка.
  • Кэш загрузки — папка CalvardCompare_cache рядом с программой: неизменённые файлы не читаются заново.
    Shift + «Загрузить» (или Shift+F5) — загрузить всё заново без кэша.
  • Над кнопкой — сколько загружено; если какой-то файл не прочитан, там красная надпись (наведите мышь).
  • Файлы из разных игр: если английские от одной игры, а русские от другой, строки не показываются —
    вместо них предупреждение. Игра определяется по папке (exe, архивы, папки script_en / script_eng,
    имя папки), а если не определилась — по совпадению команд скрипта. Ошиблась — «Всё равно показать».
  • Строки сопоставляются по устройству скрипта, а не по номеру: лишняя строка не сбивает остальные.
    Большие сцены — сначала по функциям скрипта, затем по командам и ведущему тегу реплики (<k>, <KR>…).
    «— нет —» — в этом языке строки нет. «—НЕ ТРОГАТЬ—» — текст есть, но это служебное имя
    (TXT_SAVE_NIGHTMARE, chr0000_c15), его правка сломает игру; рядом серым — само имя.
  • Перевод Daybreak, где текст функции записан дважды («calls { … } { … }»), — показывается русская копия.

──────────────────────────────── ПОИСК И ТАБЛИЦА

  • Показываются строки, где слово есть хотя бы в одном из двух столбцов.
    ё = е; тире любого вида, кавычки и многоточие считаются одинаковыми. «Учитывать регистр» —
    «Van» не найдёт «van». Несколько слов — строки, где есть все. «Целые слова»: mare найдёт «Mare's»,
    но не «Nightmare»; без галочки ищется и часть слова («кобыл» найдёт «кобыла»).
  • «Файл целиком» — все строки одного файла по порядку.
  • Синим — совпадение с поиском, жёлтым — слово из словаря и его перевод.
  • Текст переносится по строкам; ширину столбцов можно менять мышью за границу.
    Масштаб текста — Ctrl+колёсико или Ctrl+плюс / минус, Ctrl+0 — обычный (запоминается).
  • Столбец «Файл» — имя файла и номер строки в нём.
  • Правый клик по строке: «Копировать левый столбец / правый столбец / оба / имя файла»,
    «Открыть файл слева», «Открыть файл справа» — .json, .yaml, .txt открываются в Notepad++
    сразу на этой строке (без Notepad++ — программой по умолчанию); таблица .xlsx — в Excel или WPS
    на листе «Text», выделена ячейка B нужной строки (если таблица уже открыта — в ней же).
  • Ctrl+C — копирует столбец, по которому щёлкнули. Двойной клик по ячейке — поле с полным текстом,
    чтобы выделить и скопировать часть. F11 — во весь экран.
  • Прокрутка нажатым колёсиком: нажмите колёсико и ведите мышь — таблица едет сама; ещё нажатие — стоп.
  • Горячие клавиши — в конце этого файла.

──────────────────────────────── СЛОВАРЬ

  Словарь выбирается кнопкой «Выбрать…» (.dat, .json или .txt). Файл можно обновить, не закрывая программу:
  при следующем поиске он перечитается сам.
  Форматы:
    JSON: {"Bracer": "брейсер", "Spriggan": ["спригган", "спригганша"]} или [{"en": …, "ru": …}],
          комментарии //, #, /* */, "_comment"; лишняя запятая не страшна;
    текст (UTF-8 или Windows-1251): Bracer = брейсер  /  Bracer:Брейсер  /  Shizuna:Шизуна-Шизуны-Шизуне
          (падежи через тире, если начинаются одинаково; варианты через запятую; # — комментарий).
  • Подсвечивается слово из поиска, если оно есть в словаре, — в столбце того языка, на котором вы его
    написали; имя и фамилия — по отдельности; по-русски — с окончаниями («Вана» → «Ван»).
  • Рядом с «Найдено» — сколько раз русский вариант встречается в найденных строках.
  • «Отмечать «как в словаре»» — строка зелёная, если для каждого слова словаря из английского
    текста в русском стоит перевод из словаря. С «Целые слова» — только точные формы из словаря.
    Фраза из нескольких слов проверяется, только когда в английском стоит вся фраза.

──────────────────────────────── ВКЛАДКА «ПРОВЕРКИ»

  Считаются в фоне сразу после загрузки; на вкладке видно число ошибок.
  • «Служебные коды» — потерянные или лишние коды (<C…>/</C>, {11}{…}, {16}, <K>, <E…>, <B>…),
    сломанный перенос («\» без n или «\\n» текстом), изменённое служебное имя («—НЕ ТРОГАТЬ—»),
    файл .json, который не читается (с номером строки). Что значит каждый код — раздел «Служебные коды» в конце этого файла.
  • «Не переведено» — реплики сцен, оставшиеся на английском или японском (таблицы и интерфейс
    не проверяются); одинаковые — одной строкой, в скобках сколько раз. Отладочные сцены (a0…, debug,
    sample) не проверяются. Если слева японский — его типографика (фуригана <R>…, размер <s24>,
    жирный <B>, цвет <c…>…</C>) с переводом не сверяется.
  • «Подстановки» — %d, %s, %.1f…: места, куда игра подставляет число или имя. Если их в переводе
    не столько, сколько в оригинале, игра покажет не то или упадёт.
  • Одинаковые ошибки собраны в группы: «потеряно: </C> — 120 реплик», файлы и пример.
    «Показать все» (или клик по группе) раскрывает реплики группы, «Не ошибка · все» скрывает группу.
  • Кнопки «диалоги .json», «таблицы .xlsx», «интерфейс .yaml» — показать или скрыть находки этого типа.
  • «Открыть в сверке» (или двойной клик) — строка на вкладке «Сверка». Правый клик по находке —
    меню: «Открыть в сверке», «Открыть файл слева», «Открыть файл справа» (на этой строке).
  • «Не ошибка» — убрать находку; «Скрытые» — всё убранное, «Вернуть» / «Вернуть все».
  • «Выгрузить в Excel» — находки в .xlsx, лист на раздел; у каждой находки — по 5 реплик до и после
    из того же файла, как есть, со служебными кодами (находка — жёлтым), чтобы было видно, где не хватает.
  • «Проверить заново» — после правок (сначала «Загрузить»).
  • Прокрутка нажатым колёсиком: нажмите колёсико и ведите мышь — список едет сам; ещё нажатие — стоп.

──────────────────────────────── ПОРТРЕТЫ

  У реплик из t_active_voice.xlsx (фразы персонажей на ходу) слева в колонке файла — портрет говорящего.
  Говорящий берётся из записи таблицы (номер персонажа → его модель в t_name), картинка — та же, что в игре
  рядом с фразой (из face_c####; у кого её нет — btlface0_c####). Выражение лица не учитывается.
  У безымянных NPC портретов нет. Портреты лежат в «data.dat» (у каждой игры свои).
  У реплик сцен портрет ставится по ID говорящего (system[5,6](ID, …) → его модель). Показываются те же портреты,
  что и у t_active_voice: у кого такого портрета нет, тот остаётся без него.

──────────────────────────────── ЗНАЧКИ ВМЕСТО КОДОВ <I…>

  Только на экране, в файлы ничего не пишется. Кнопка «Значки: …» в строке настроек открывает окно.
  • Картинки — в файле «data.dat» рядом с программой (зашифрован; распакуйте архив целиком).
    В окне выберите игру: Daybreak 1, Daybreak 2 или Horizon (по умолчанию Horizon) — у каждой своя
    icons.png (предметы, статусы, «!»-точки — коды <I0>…<I440>); кнопки ph3_button_prompts.png общие:
    PlayStation, Xbox, Switch, Steam Deck, Stadia, клавиатура и мышь. «Устройство» — чьи значки показывать.
  • Коды 900 и выше — «действия» (меню, атака, поиск осколков). Большая часть назначена по файлам
    раскладки и экранам игры и показывается сразу (например 900 ×, 901 ○, 912 R3, 1016 L1, 1120–1129 —
    меню быстрого доступа L2). Код без значка — серая рамка с числом; назначьте его один раз в окне:
    выберите код и нажмите кнопку в палитре (Ctrl+клик — комбинация, например 910 = L2+R2).
    Кнопка геймпада назначается «по месту» — на всех геймпадах сразу; клавиатуре — отдельно.
  • Значки и в таблицах, как в игре: предметы t_item (по t_item.tbl из _original проекта), ремёсла t_skill
    (тип и сила), статусы t_condition_info и подсказки t_itemhelp, дальность ремёсел, эффекты, стихии,
    надписи интерфейса, у которых игра сама рисует значок (легенда карты, награды, кнопки меню).

──────────────────────────────── ФАЙЛЫ РЯДОМ С ПРОГРАММОЙ

  KaiCompare.ini — настройки (папки, словарь, тема, где вы остановились, масштаб);
  CalvardCompare_buttons.txt — назначения кнопок;
  CalvardCompare_cache — кэш загрузки и английских файлов из папки игры, там же CalvardCompare_hidden.txt —

  data.dat — значки и портреты.

КОМАНДНАЯ СТРОКА
  CalvardCompare <английская папка> <русская папка> <слово> — поиск в консоли (DICT=<словарь> — с подсветкой).

──────────────────────────────── СЛУЖЕБНЫЕ КОДЫ

Главное правило: все коды из английской строки должны остаться в русской — столько же и тех же.
Переводится только текст между ними. Сверка сравнивает коды в каждой строке и показывает,
что потеряно или лишнее.

Пояснения ниже — из отладочных сцен самой игры (там разработчики подписали, что делает код)
и по тому, как коды стоят в тексте. Где назначение не подтверждено, так и написано.
В скобках — сколько раз код встречается в английском тексте трёх игр.

──────────────────────────────── ПЕРЕНОС СТРОКИ

\n      новая строка в окне диалога. В .json пишется ровно так: обратная косая черта и буква n.
        Если написать только «\» (без n) — файл не прочитается или диалог дальше не пойдёт.
        Если написать «\\n» — в игре будет видно «\n» текстом. Сверка ловит оба случая.

──────────────────────────────── ЛИЦО ГОВОРЯЩЕГО (окно с портретом)

<K>     портрет говорящего, обычное положение — предположительно (11 336)
<KL>    портрет слева — предположительно, по аналогии с <KR> (7 265)
<KR>    портрет справа (14 449) — в отладке игры: «Face right»
<k>     портрет слева, уменьшенный (13 732) — в отладке: «Face left - smaller»
<kR>    портрет справа, увеличенный (14) — в отладке: «Face right - larger»
        Ставятся в начале реплики. Не удалять и не переносить в середину.

──────────────────────────────── ЦВЕТ И ВИД ТЕКСТА

<C1> … <C9>   начало цветного текста (номер — цвет из палитры игры) (11 442)
</C>          конец цветного текста — вернуть обычный цвет (812)
              Если </C> потерян, всё после этого места окрасится цветом <C…>.
              <C> без номера встречается редко — видимо, тоже возврат цвета (не подтверждено).
<c698> … </c> цвет по коду RGB — в отладке: «Change text color (RGB)» (78 / 21)
<B> … </B>    жирный текст — в отладке: «Set whole row of text to bold» (72 / 75)
<S3>          размер текста — в отладке: «Change text size» (1 392)
<s40>         размер текста (маленький вариант) — например «<s40>The next day...» (183)
{tab}         отступ (табуляция) (34, только Horizon)

──────────────────────────────── СКОРОСТЬ И ПАУЗЫ

<W200>   скорость вывода текста — в отладке: «Change text display speed» (784)
<w1000>  пауза вывода текста на время (число — миллисекунды) — в отладке:
         «Stop text display for a set amount of seconds» (454)

──────────────────────────────── ЭМОЦИИ И ЗНАЧКИ

<E0>     эмоция над персонажем — в отладке: «Display PA emotion» (323)
<Es5>    эмоция без звука — в отладке: «Display emotion (No SE)» (6)
<#E_1>, <#E_A>, <#S[1]>, <#P_1>, <#H[2]>  особые эффекты в реплике (единицы случаев,
         назначение не подтверждено) — оставлять как в оригинале
<I210>   значок кнопки или иконка в тексте (например кнопка O) — в отладке: «O Button» (164)
<R>      встречается один раз в отладке Horizon — назначение неизвестно

──────────────────────────────── КОДЫ В ФИГУРНЫХ СКОБКАХ {число}

{число}  служебные значения игры (3 212). Стоят парами или по одному, обычно в конце строки
         или вместо названия. Что известно:
  {21}{2007}   название приёма (S-Craft) по номеру — игра подставит название сама
  {17}{2005}   название предмета по номеру
  {11}{41957}  ссылка на озвучку реплики (номер голосового файла). Если потерять —
               реплика может остаться без голоса
  {16}, {13}, {7}  ставятся в конце строки; по виду — ожидание нажатия / закрытие окна,
               точное назначение не подтверждено
  {0} и другие — назначение неизвестно
         Все {числа} оставлять ровно как в оригинале, в том же месте.

──────────────────────────────── ПОДСТАНОВКИ

$1, $2   в поле "code" — места, куда игра подставит текст. Сами строки "text" не трогают их.
